## RĂSPUNSURI ORIENTATIVE (pentru corectare)

### Ex. 1 — Selectiv:
- *băiatul* — M, sg., N, subiect
- *morarului* — M, sg., G, atribut substantival genitival
- *pădure* — F, sg., Ac, complement circumstanțial de loc
- *lumina* — F, sg., N, subiect
- *soarelui* — M, sg., G, atribut substantival genitival
- *crengile* — F, pl., Ac, complement circumstanțial de loc
- *câinele* — M, sg., N, subiect
- *familiei* — F, sg., G, atribut substantival genitival
- *glasul* — M, sg., N, subiect
- *vântului* — M, sg., G, atribut substantival genitival

### Ex. 2:
a) Nominativ / Subiect  
b) Genitiv / Atribut substantival genitival  
c) Dativ / Complement indirect  
d) Acuzativ / Complement circumstanțial de loc  
e) Vocativ / (fără funcție sintactică)  
f) Genitiv / Atribut substantival genitival  
g) Acuzativ / Complement direct  
h) Genitiv / Atribut substantival genitival  
i) Acuzativ / Complement circumstanțial de loc  
j) Vocativ / (fără funcție sintactică / în afara relațiilor sintactice)
