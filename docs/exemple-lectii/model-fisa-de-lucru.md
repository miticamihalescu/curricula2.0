### Tipuri de exerciții recomandate (variație obligatorie)

#### 1. Exercițiu tip GRILĂ / ALEGERE MULTIPLĂ
```
I. Încercuiește litera corespunzătoare răspunsului corect:          (__ puncte)

1. [Întrebarea]
   a) [Varianta A]
   b) [Varianta B] ← corectă
   c) [Varianta C]
   d) [Varianta D]

2. [Întrebarea]
   a) [Varianta A]
   b) [Varianta B]
   c) [Varianta C] ← corectă
   d) [Varianta D]
```

#### 2. Exercițiu tip ADEVĂRAT / FALS
```
II. Notează A (Adevărat) sau F (Fals) în dreptul fiecărei afirmații:    (__ puncte)

1. ___  [Afirmație despre subiect]
2. ___  [Afirmație despre subiect]
3. ___  [Afirmație despre subiect]
4. ___  [Afirmație despre subiect]
```

#### 3. Exercițiu tip COMPLETARE
```
III. Completează spațiile libere cu informațiile corecte:              (__ puncte)

1. [Enunț cu spații goale _______________ și _______________ ]
2. [Enunț cu spații goale _______________ ]
3. [Definiție cu spații goale: _______________ este _______________ ]
```

#### 4. Exercițiu tip ASOCIERE / CORESPONDENȚĂ
```
IV. Unește prin săgeți elementele din coloana A cu cele din coloana B:  (__ puncte)

    Coloana A                    Coloana B
1. [Element 1]              a) [Corespondent]
2. [Element 2]              b) [Corespondent]
3. [Element 3]              c) [Corespondent]
4. [Element 4]              d) [Corespondent]
```

#### 5. Exercițiu tip RĂSPUNS SCURT
```
V. Răspunde în 2-3 propoziții la următoarele întrebări:               (__ puncte)

1. [Întrebare deschisă care testează înțelegerea]
   ___________________________________________________________________
   ___________________________________________________________________

2. [Întrebare deschisă]
   ___________________________________________________________________
   ___________________________________________________________________
```

#### 6. Exercițiu tip APLICAȚIE / PROBLEMĂ
```
VI. Rezolvă problema/aplicația:                                        (__ puncte)

[Enunțul problemei / situației aplicative]

Rezolvare:
___________________________________________________________________
___________________________________________________________________
___________________________________________________________________
___________________________________________________________________
```

#### 7. Exercițiu tip ANALIZĂ / INTERPRETARE (pentru clasele mari)
```
VII. Analizează [textul / graficul / imaginea] de mai jos și răspunde:  (__ puncte)

[Textul / datele de analizat]

a) [Prima întrebare de analiză]
b) [A doua întrebare de analiză]
c) [Întrebare de opinie / argumentare]
```

## BAREM DE NOTARE / CORECTARE

```
BAREM DE CORECTARE

I.   __ x __ puncte = __ puncte
II.  __ x __ puncte = __ puncte
III. __ x __ puncte = __ puncte
IV.  __ x __ puncte = __ puncte
V.   __ x __ puncte = __ puncte
VI.  __ puncte (câte __ puncte per pas)
VII. __ puncte

Din oficiu: 10 puncte
TOTAL: 100 puncte

Notă: Punctajul total (fără punctele din oficiu) se împarte la 9.
Sau: Se acordă nota direct conform baremului de 10 puncte.
```

---

## NOTE PENTRU GENERARE AI

1. **Variație obligatorie** — fișa trebuie să conțină cel puțin 3 tipuri diferite de exerciții
2. **Dificultate progresivă** — de la exerciții simple (recunoaștere) la complexe (aplicare, analiză)
3. **Punctajul** trebuie distribuit logic: exercițiile mai grele = mai multe puncte
4. **Total** 100 puncte (sau 10 puncte + din oficiu)
5. **Limbaj clar** — elevul trebuie să înțeleagă cerința fără explicații suplimentare
6. **Context real** — exercițiile aplicative trebuie să aibă context din viața reală
7. Fișa de lucru se rezolvă **în clasă** (nu temă) — durata ~15-20 minute
