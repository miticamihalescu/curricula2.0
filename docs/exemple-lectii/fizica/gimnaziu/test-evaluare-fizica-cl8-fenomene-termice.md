### Subiectul 6 — Problemă de calcul (2p)

**Date:** O bilă de plumb (c_Pb = 130 J/kg·K) cu masa necunoscută m este încălzită la temperatura de 100°C, apoi introdusă în 200 g de alcool (c_alcool = 2400 J/kg·K) la temperatura de 20°C. Temperatura de echilibru este 30°C.

**Cerință:** Determină masa bilei de plumb.

*Rezolvare:*
- Căldura primită de alcool: Q_alcool = m_alcool · c_alcool · ΔT_alcool = 0,2 · 2400 · (30 – 20) = 4800 J
- Căldura cedată de plumb: Q_Pb = m_Pb · c_Pb · ΔT_Pb = m_Pb · 130 · (100 – 30) = 9100 · m_Pb
- Ecuația calorimetrică: Q_cedată = Q_primită → 9100 · m_Pb = 4800 → **m_Pb ≈ 0,527 kg**

### Subiectul 7 — Problemă de calorimetrie (2p)

**Date:** O piesă de nichel (c_Ni = 460 J/kg·K) cu masa m = 2 kg se răcește de la 2000°C la 1000°C.

**Cerință:** Calculați căldura degajată de piesa de nichel.

*Rezolvare:*
```
Q = m · c · ΔT = 2 · 460 · (2000 – 1000) = 2 · 460 · 1000 = 920 000 J = 920 kJ
```

**Răspuns: Q = 920 kJ**
