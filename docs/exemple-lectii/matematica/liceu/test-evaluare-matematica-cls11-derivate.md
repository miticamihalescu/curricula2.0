## SUBIECTUL II — (30 puncte)

**II.1.** (10p) Fie f: ℝ → ℝ, f(x) = x³ − 6x² + 9x − 2.
a) Calculați f'(x) și f''(x).
b) Determinați intervalele de monotonie ale lui f.
c) Aflați punctele de extrem local (maxim și minim local).

**II.2.** (10p) Ecuația tangentei la graficul funcției f(x) = x² − 4x + 7 în punctul de abscisă x₀ = 3 este:
a) Calculați f(3) și f'(3).
b) Scrieți ecuația tangentei: y − f(x₀) = f'(x₀)(x − x₀).

**II.3.** (10p) O companie produce zilnic x unități dintr-un produs. Costul total este C(x) = x² − 20x + 200 (lei). Veniturile sunt V(x) = 60x.
a) Scrieți funcția profit P(x) = V(x) − C(x).
b) Determinați producția x pentru care profitul este maxim.
c) Calculați profitul maxim.

## SUBIECTUL III — (30 puncte)

**III.1.** (15p) Fie f: (0,+∞) → ℝ, f(x) = x − ln(x).
a) Calculați f'(x).
b) Studiați monotonia funcției și determinați minimul global.
c) Demonstrați că f(x) ≥ 1 pentru orice x > 0.

**III.2.** (15p) Se consideră funcția f(x) = ax² + bx + c care satisface: f(0) = 1, f'(0) = −2 și f(1) = 0.
a) Determinați a, b, c.
b) Scrieți complet f(x) și studiați convexitatea/concavitatea graficului.
c) Aflați dacă f are zerourile în ℝ și calculați-le.
