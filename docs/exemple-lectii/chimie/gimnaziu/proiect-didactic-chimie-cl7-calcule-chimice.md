## 7. CONȚINUT ȘTIINȚIFIC — FIȘA DE LUCRU

### Exercițiul 1 — Masă molară (completare tabel)

| Substanță | Formula chimică | Masa molară M (g/mol) |
|-----------|----------------|----------------------|
| Apă | H₂O | 2×1 + 16 = **18** |
| Dioxid de carbon | CO₂ | 12 + 2×16 = **44** |
| Amoniac | NH₃ | 14 + 3×1 = **17** |
| Clorură de sodiu | NaCl | 23 + 35,5 = **58,5** |
| Sulfat de calciu | CaSO₄ | 40 + 32 + 4×16 = **136** |
| Glucoză | C₆H₁₂O₆ | 6×12 + 12×1 + 6×16 = **180** |

### Exercițiul 2 — Raport atomic

**Problemă:** O substanță conține 2 atomi de hidrogen și 1 atom de oxigen.
Raport atomic H:O = 2:1 → Formula chimică: **H₂O**

### Exercițiul 3 — Formulă din raport de mase

**Problemă:** O substanță conține 40% Ca, 12% C, 48% O.
```
Ca: 40/40 = 1
C:  12/12 = 1
O:  48/16 = 3
Raport atomic: Ca:C:O = 1:1:3 → Formula empirică: CaCO₃ (carbonat de calciu)
```

### Exercițiul 4 — Compoziție procentuală

**Problemă:** Calculați procentul masic al fierului în oxid feric Fe₂O₃.
```
M(Fe₂O₃) = 2×56 + 3×16 = 112 + 48 = 160 g/mol
%Fe = (2×56 / 160) × 100 = (112/160) × 100 = 70%
%O  = (48/160) × 100 = 30%
```

### Exercițiul 5 — Calcul mol ↔ grame

**Problemă:** Câți grame de NaOH (hidroxid de sodiu) se găsesc în 3 moli?
```
M(NaOH) = 23 + 16 + 1 = 40 g/mol
m = n × M = 3 × 40 = 120 g
```

**Problemă inversă:** Câți moli sunt în 88 g de CO₂?
```
M(CO₂) = 44 g/mol
n = m/M = 88/44 = 2 moli
```

## 8. FORMULELE ESENȚIALE

| Formulă | Notație |
|---------|---------|
| Masă molară | M = suma maselor atomice (g/mol) |
| Numărul de moli | n = m / M |
| Masa substanței | m = n × M |
| Compoziție procentuală | % element = (nr_atomi × M_atom / M_substanță) × 100 |
